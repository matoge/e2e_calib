# 特許クレーム ドラフト（日本語版）

## テーマ

**マルチモーダル統合前の「残留不確実性」予測に基づく、決定論的トークン凝縮アーキテクチャ**

LiDARとカメラを混ぜる「前」に、LiDARだけで「画像を合わせてもなお難所であろう場所」を予見し、計算資源をそこに集中投下する。Top-Kでもランダムでもない、分散重み付き最遠点サンプリング（WFPS）による決定論的な選別を行う。

---

## ターゲット

- 自動運転・ADAS向けマルチモーダル3D知覚モデル（LiDAR×Camera）
- BEVFormer / DETR3D / Sparse4D 等のクエリベース検出・セグメンテーション
- 車載エッジ推論（決定論性が必須な領域）
- 将来的には任意の異種センサ統合（Radar、Thermal、IMU等）にも拡張可能

クエリ数が数百〜数千規模に膨らんでも破綻しない、リアルタイム性が要求されるシステム全般。

---

## 課題

### 1. 富豪的計算によるレイテンシ爆発
既存手法（BEVFormer / DETR3D 等）はクエリ全件（例: 1000個）を重い統合処理（Cross-Attention）に突っ込むため、計算量が O(N²) で爆発する。

### 2. 事後選別の本質的な無駄
DETR系のTwo-stage Query Selectionは「統合した後のクラス確信度」でトークンを間引く。これは答えが出てから捨てる行為であり、重い統合処理そのもののコストは削減できていない。

### 3. Top-Kサンプリングの情報冗長性
分散・スコアの上位だけを取ると、1つの物体周辺にクエリが密集し、地面・遠方・遮蔽境界など「シーンの骨組み」を構成する情報が捨てられる。

### 4. ランダムサンプリングの非決定性
推論ごとに結果がブレる手法は、機能安全（FuSa）が要求される車載システムでは採用不可。

### 5. 既存「平均ベース」予測の脆さ
単一センサ（LiDAR）から物体クラスや位置の「平均（予測値）」を直接出させても、情報が足りないため誤った確信を持つだけ。「平均」をゲートに使うと予測バイアスを引きずる。

## アプローチ

### 全体構成（3段構え）

```
[LiDAR点群] → [Backbone] → [共有予測ヘッド (μ, σ²)]
                                ↓ (σ²のみ使用、μは破棄)
                          [残留不確実性マップ]
                                ↓
                          [WFPS: 分散重み付き最遠点サンプリング]
                                ↓ (1000 → 16 トークンに凝縮)
                          [Sparse Cross-Attention with Image]
                                ↓
                          [Final Prediction]
```

### Step 1: 残留不確実性の「先出し」予測
- LiDARのみのローカル特徴量から、**統合後にもなお残る不確実性 σ²** を予測するヘッドを設置
- 共有ヘッドだが、**平均 μ は破棄、分散 σ² のみをサンプリングのゲートに使用**
- 学習は Aleatoric Loss で行う:

$$L_{aleatoric} = \sum_i \left( \frac{\|y_i - \hat{y}_i\|^2}{2\sigma_i^2} + \frac{1}{2}\log\sigma_i^2 \right)$$

これにより、「画像と混ぜてもなお解けなさそうな場所」が高 σ² として浮かび上がる。

### Step 2: WFPS（分散重み付き最遠点サンプリング）

Top-Kの「密集」問題と、ランダムの「非決定性」問題を同時に解決する独自の決定論的サンプリング。

**選択スコア:**

$$S_i = \sigma_i^2 \times \min_{j \in \text{Selected}} \| \text{pos}_i - \text{pos}_j \|$$

1. 最も σ² が高い1点を起点に決定論的に選出
2. 以降、「不確実性 × 既選択点からの距離」が最大の点を反復選出
3. K個（例: 16個）に達するまで継続

効果:
- **精鋭部隊**: 高 σ² の難所がまず確保される
- **シーンの骨組み**: 周囲に誰もいない地面・遠方も距離項で救済される
- **完全な決定論性**: 同じ入力なら必ず同じ16個

### Step 3: Sparse Fusion
凝縮された16トークンに対してのみ、重い Cross-Attention（画像との統合）を実行。
計算量は O(N²) → 実質定数オーダー。

### Step 4: 微分可能性の担保
サンプリング自体は微分不可能だが、以下の二経路で学習可能:
- **Deep Supervision**: 全1000クエリに対する σ² 予測ロスをセレクタヘッドに直接付与
- **Straight-Through Estimator (STE)**: 選択された16トークンの重みを通じて、後段ロスからの勾配をセレクタにバイパス

## 既存開発資料 / 先行技術調査

### カテゴリA: 確信度・不確実性ベースのクエリ選別

| 先行技術 | 仕組み | 本発明との決定的違い |
|---------|--------|---------------------|
| **RT-DETR「Uncertainty-Minimal Query Selection」** (Zhao et al., 2304.08069) | エンコーダ特徴から、**不確実性が最小（位置確信度が高い）**ものを上位300個選別 | **逆極性**: 既存は「確信が高い＝答えに近いもの」を選ぶが、本発明は「統合後もなお難しいもの」を選ぶ。さらに既存は**単一モダリティ**で画像エンコーダ後に動作するが、本発明は**統合前**にLiDAR単体の信号で動作する |
| **DETR / Two-stage Deformable DETR** | エンコーダ後の Objectness で Top-K | 単一モダリティ・統合後選別。不確実性を一切使用しない |
| **DQ-DETR** | カウント予測で動的にクエリ数を決定 | 「数」を決めるだけで「どれを選ぶか」のロジックではない |
| **IoU-aware Query Selection** | 予測IoUで選別 | 確信度ベース。情報利得ベースではない |

### カテゴリB: マルチモーダル・トークン枝刈り

| 先行技術 | 仕組み | 本発明との決定的違い |
|---------|--------|---------------------|
| **MADTP** (Cao et al., CVPR 2024) | モダリティ間の特徴アライメントスコアで枝刈り | **両モダリティが揃っている必要がある**。本発明は重い側を呼ぶ前に単一モダリティで足切り |
| **Multimodal Token Fusion** (CVPR 2022) | 各モダリティ独立に枝刈り→再利用 | 「統合後に何が困難になるか」を予測する概念がない |
| **HiRED** (Attention-Guided Token Dropping) | Attention重みでトークンを捨てる | Attention計算が前提 → 統合前ゲートではない |

### カテゴリC: 点群サンプリング

| 先行技術 | 仕組み | 本発明との決定的違い |
|---------|--------|---------------------|
| **Farthest Point Sampling (FPS)** | 幾何学的距離のみ | 情報重みなし。点を均等に扱う |
| **Density-Aware FPS** (2509.13213, 2025) | 局所点密度で重み付け | 密度は**幾何学的事前情報**。学習された後段予測信号ではない |
| **Curvature-Informed FPS** (2411.16995) | 曲率で重み付け | 同上、幾何のみ |
| **SampleNet / Gumbel Subset Sampling** | 微分可能な**確率的**サンプリング | 非決定論的 → 機能安全の要件を満たさない。本発明は決定論を保持したまま Deep Supervision + STE で学習 |
| **APES (Edge Sampling)** | Attentionでエッジ点を抽出 | 単一モダリティ・幾何顕著性。後段の統合との関係性なし |
| **SAMBLE** (CVPR 2025) | 形状特化サンプリング | 単一モダリティ・形状解析。統合ゲートではない |
| **CP-Net** | グローバルmax-pool寄与で決定論サンプリング | 決定論性は共通だが、基準が「再構成寄与」であり「統合後残留不確実性」ではない |

### カテゴリD: 一般的なTransformerトークン削減

| 先行技術 | 仕組み | 本発明との決定的違い |
|---------|--------|---------------------|
| **DynamicViT** | 中間層で Attention 重みからトークン削減 | Attention計算が必須 → 統合前ゲートではない |
| **US10740433B2 (Universal Transformers)** | トークンごとの適応的計算深さ | 深さ調整であり選別ではない。マルチモーダル要素なし |
| **US20230112862A1 (Reuse Transformers)** | 層間で Attention スコアを再利用 | 計算再利用であり、トークン選別ではない |
| **US20260050766 (SSM Token Compression)** | SSMでトークンを圧縮要約 | 集約・圧縮であり、選別ではない。マルチモーダルゲートではない |
| **vAttention** | 疎Attentionに(ε,δ)保証 | Attention演算自体の近似。クエリ数は減らない |

### カテゴリE: LiDAR-カメラ統合アーキテクチャ

| 先行技術 | 仕組み | 本発明との決定的違い |
|---------|--------|---------------------|
| **Li-ViP3D++ (Query-Gated Deformable Fusion)** | クエリ由来の重みで Deformable Cross-Attention をゲート | 「各クエリの注目度合い」をゲートするが「どのクエリが通過するか」は選別しない。全クエリが統合コストを払う |
| **DeepFusion / VAD** | 不確実性モジュールでノイジーなモダリティを抑制 | **モダリティ単位**の信号品質を扱う。本発明は**クエリ単位**で統合後残留難易度を予測 |
| **SAMFusion** (Princeton, 2024) | 天候変動下のセンサ適応統合 | モダリティ重み付け。クエリレベルの資源配分ではない |
| **Mobileye カメラ-LiDAR統合特許群** | キャリブレーション、相対変換のオンライン推定 | 問題領域が完全に異なる |
| **Sparse4D / SparseFusion** | クエリベース疎4Dサンプリング | **全クエリを保持**したまま、各クエリの注目範囲を疎にする。クエリ数自体は削減しない |

## 差別化の4本柱（防衛ロジック）

### 柱1: 極性の反転 — 「易しい場所ではなく難しい場所を選ぶ」
既存のクエリ選別手法（DETR系、RT-DETR、IoU-aware）はすべて「答えに最も自信があるクエリ」を選ぶ。本発明はあえて「統合後もなお残る不確実性が最大のクエリ」を選ぶ。これは正反対の評価軸であり、設計思想が根本的に異なる:**答えを確認する場所ではなく、答えを変える場所に計算を投入する**。

### 柱2: 統合前ゲート — 「重い側を呼ぶ前に決める」
MADTP、HiRED、DynamicViT等は、すべて高コスト計算が**少なくとも開始された後**に枝刈りを行う（Attentionスコアやモダリティ間アラインメントの計算が先行）。本発明は**第2モダリティを参照する前**に、第1モダリティの特徴だけでゲートを行う。重い統合パスは K << N のトークンに対してのみ起動される。

### 柱3: 分散のみのヘッド出力 — 「μ を捨てて σ² でゲート」
共有予測ヘッドの標準的な使い方は平均出力を**利用する**ことだが、本発明は μ を意図的に破棄し σ² のみをゲートに使う。これにより単一モダリティの過信が選別を汚染するのを防ぐ。「共有ヘッド、平均破棄、分散のみゲート」を構造的に強制する先行技術は確認できなかった。

### 柱4: 決定論的・情報重み付き多様性サンプリング（WFPS）
- **標準FPS / DA-FPS / Curvature-FPS**: 決定論的だが**幾何学的事前情報のみ**で重み付け
- **Gumbel Sampling / SampleNet**: 情報利得を考慮するが**確率的**
- **Top-K**: 情報利得を考慮するが**密集**する

本発明の **WFPS** は、以下の3つの望ましい性質を同時に満たす唯一の手法:
1. 決定論的（機能安全と整合）
2. 学習済み情報信号（予測残留不確実性）で重み付け
3. 空間的多様性（距離項によりシーン骨組みを救済）

これら3つすべてを兼ね備えた先行技術は確認できなかった。

## 推奨される独立クレーム1（再定式化）

先行技術の状況を踏まえ、独立クレーム1には**4本柱すべて**を明示的に組み込み、単一の先行技術で読まれることを防ぐ:

> **請求項1.** マルチモーダルセンサ統合のための方法であって、以下の各ステップを含む:
> (a) **第1の**センサモダリティから局所特徴量を抽出するステップ;
> (b) 前記局所特徴量から、平均推定値も出力する予測ヘッドを介して、特徴量ごとに、**第2の**センサモダリティとの統合後にもなお残ると期待される予測残留不確実性を算出するステップであって、**前記平均推定値はステップ(c)の選別には用いられない**;
> (c) (i) 予測残留不確実性と (ii) 既選択特徴量からの特徴空間または空間距離の最小値、の結合基準を最大化する**決定論的**手順により、特徴量のサブセットを選別するステップ;
> (d) 選別された前記サブセットに対してのみ、前記第2のセンサモダリティとのクロスモーダル統合を行い、選別されなかった特徴量に対しては当該統合を行わないステップ。

(b)の「平均破棄」、(c)の「決定論的・不確実性重み付き多様性」、(d)の「統合前ゲート」の組み合わせは、調査範囲の文献上、新規である。

## 拒絶対応の戦術メモ

最も可能性が高い102/103引用は **RT-DETR (Zhao et al., 2304.08069)** の「不確実性ベースのクエリ選別」。最強の反論ロジック:

> RT-DETRは**単一画像モダリティ**内で、エンコーダ実行後に**不確実性が最小**（高確信な位置推定）のクエリを選別する。本発明は**単一モダリティ**内で、第2モダリティが起動される**前**に、**不確実性が最大**の特徴量を選別する。これはクロスモーダル計算資源を配分するという明示的な目的のためである。両者は、パイプライン上の正反対の地点で正反対の信号を最適化しており、組み合わせても本発明には到達しない。

## 想定実施例（明細書用シナリオ）

- 遠方の小物体（LiDAR点群が疎で、画像と合わせてもなお曖昧）
- 遮蔽物の陰（部分観測下の物体推定）
- 悪天候時の境界判定（霧・降雨でカメラも信頼度低下）
- 透明物体（ガラス・反射面）など、両モダリティが苦手な領域

これらの「両方を合わせても難しい」シナリオで計算資源を集中投下することにより、精度を維持しつつスループットを大幅に向上できることを実験的に示す。

Deformable Cross-Attention
で CalibNetDepth を強化する

画像側の K/V に対する attention を全画素 softmax ではなく学習された N 個の サンプリング点に絞る multi-scale deformable attention (DINO 由来) を、 CalibNetDepth の cross-attn ブロックに移植。bf16-native CUDA カーネルで ベースラインと同速を維持しつつ val NLL 2.074 → 1.57 の 改善を確認。

動機

元の CrossAttentionBlockCov はクエリ (point query) と K/V (画像特徴 H×W) 全画素で dense softmax を取る。画像サイズ 64×64 から ConvNeXt で降りた coarse (16×16=256) / fine (32×32=1024) でも十分軽いが、"どこを見るか" を attention score に全委任しているため 学習の肝になる。

deformable attention は hard-coded に "各 head × 各レベル × N=4 点" を サンプリングしてから加重和するので、attention 計算量 O(Q·K) が O(Q·N) に落ち、かつ "どこを見るか" が explicit にオフセット予測として 出てくる。このオフセットが結果的に 局所的な幾何補正の吸収器 として機能するという仮説を立てた。

実装

DINO の ops/ (MSDeformAttn CUDA kernel) をそのまま持ち込み、 bf16 autocast の内側でも動くよう AT_DISPATCH_FLOATING_TYPES_AND2 と gpuAtomicAdd ベースに書き換え。これで fp32 キャストなしで そのまま kernel 実行 できる。

3 モード

deform_mode = 'none'  # 旧 CrossAttentionBlockCov（ベースライン）
deform_mode = 'sl'    # 単一レベル版: 各ブロックが 1 レベル (coarse or fine)
                      #   を N=4 点でサンプル
deform_mode = 'ml'    # 多レベル版: 各ブロックが coarse+fine の両方を
                      #   N=4 点ずつ + 学習可能な level embedding

CalibNetDepth(deform_mode=…) で切替。ML mode は self.level_embed = nn.Parameter(zeros(2, d)) の追加パラメータ (≈512 params) のみ。

主要所見:
  • SL / ML どちらも ~0.5 NLL の明確な改善。ML の複雑化は追加の勝ちを生まず、SL で十分。
  • bf16 カーネルのおかげでベースラインと ほぼ同速 (19.3 vs 19.5 ms/iter)。
  • BA 下流でも優位: pinhole の t_err が all_v3_mc の 2.10 cm から 1.60 cm に改善 (ML) — 詳細は BA report 参照。

Downstream: 暗黙の歪み吸収

BA 感度スイープ で面白いパターンが出た。 all_v3_mc (pinhole 訓練) では k₂ = +0.01 を BA に注入すると t_err が 2.10 → 1.56 cm に改善 (= PandaSet に微小 pincushion があることを示唆)。 一方、deformable 2 モデルは pinhole 単体で既に最良で k₂ を入れても改善しない。

これは deformable attention が学習中にサンプリングオフセットを自動調整する過程で、 各点が画像のどこを見るかを空間的に歪めて学んでいることを意味する。 微小 radial 歪みが implicit に吸収され、 明示的な distortion モデルを下流で足す必要がなくなる。 extrinsic BA にとっては "正しい (u,v) を見る" 事ができれば十分で、 歪み補正は network の表現空間に閉じ込められて良い。

躓いた箇所

Block 順の silent refactor バグ (85b6ccc): deformable を足す refactor で n_layers≥3 の時のブロック実行順が 崩れ、cross_fine と cross_refine が feature レベルを 取り違えるバグを混入。pre-refactor の all_v3_mc ckpt を load_state_dict で読み込むと silently mis-wired になり、BA で t が GT drift のまま動かなくなる。
→ 修正コミット 4517107/45b9fcb で元の coarse → refine → fine → fine2 順を復元。deform 訓練済み重みも 壊さないよう deform_mode で条件化して共存。

次のステップ

  • N_points スイープ — N=4 固定だが、N=8 / 2 での差を見たい。attention の粒度 vs. overfitting のトレードオフ。
  • DN / query denoising 導入 — DINO-style の訓練安定化技法と組み合わせて学習時間短縮できるか。
  • deformable kernel を GS query net に流用 — patch-warp 案 と接続。3D primitive (surfel / gaussian) から (Δu, Δv, Σ) を予測する一般化した残差ヘッドに移植。

Calibration API · v0.2 raw frame

v0.2 takes a raw kamikado-format frame (image + points_V_*.txt + calib.calib) and slices it server-side into 256² sub-crops, batches them through the σ-head, and runs one closed-form Gauss-Newton step. Same engine as v0.1, no LMDB tile required. Two flows below — pick a server-side scene for a GT demo, or upload your own three files. The v0.1 page is unchanged.

1 · GT demo (server-side scene)

Pick a scene already on the server (under /raw/kamikado/scenes), pick a frame, set the perturbation, and the API perturbs the GT for you.

API reference (v0.2)

Endpoints

MethodPathPurpose
GET/api/scenes list kamikado scenes available on the server.
POST/api/calibrate_scene GT-demo: server loads scene/frame, applies perturbation, solves.
POST/api/calibrate_frame multipart upload: image + points_V + calib.calib → δ̂.
GET/api/history?limit=20 most recent calibration calls, newest first.

POST /api/calibrate_scene — JSON

{
  "scene": "points_ip664_D_20260226_224648_d005_3000_3020",
  "frame": 0,
  "ypr":   [0.30, -0.20, 0.50],
  "t":     [0.030, -0.020, 0.040],
  "cs":    256
}

POST /api/calibrate_frame — multipart

curl -X POST http://172.16.200.185:8082/api/calibrate_frame \
  -F image=@image_0.png \
  -F points=@points_V_0.txt \
  -F calib=@calib.calib \
  -F 'ypr=[0.30,-0.20,0.50]' \
  -F 't=[0.030,-0.020,0.040]' \
  -F cs=256 \
  -F scene_id=mycar -F frame_id=0

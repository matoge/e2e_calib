API reference

The same engine that powers the form is exposed as a tiny JSON API. Hit POST /api/calibrate with a perturbation, get back the shared-frame δ̂ and the 3-panel overlay PNG. The model is GPU-resident, so a request is one forward pass and one closed-form Gauss-Newton step.

Endpoints

MethodPathPurpose
GET /api/default metadata for the default sample (idx=17) + the 4 presets used by this UI.
GET /api/frames catalog of fisheye frames in the val split with ≥4 sibling tiles. Each entry is one frame you can anchor on.
GET /api/frame/{first_idx} parent-tile PNG + size for a specific frame. Used by the random-frame picker above.
POST /api/calibrate perturb-and-recover. Returns δ̂, pre/post reproj px, and a 3-panel overlay URL.

Request body for POST /api/calibrate

{
  "ypr":         [roll_deg, pitch_deg, yaw_deg],   // ZYX-Euler, deg
  "t":           [tx_m, ty_m, tz_m],               // metres
  "mode":        "tile_only" | "whole_frame" | "random_val",
  "n_tiles":     1..400,                            // number of source tiles to batch
  "cs":          256 | 512,                         // sub-crop side, px
  "target_idx":  17,                                // first_idx from /api/frames; 17 = default
  "seed":        1008                               // only used when mode=random_val
}

mode=tile_only uses only the anchor tile (≤4 sub-crops at cs=256). whole_frame uses every sibling tile of the same (scene, cam, frame). random_val samples random val tiles globally — the headline mode in the paper (200 tiles × 4 sub-crops ≈ 800 sub-crops).

Response

{
  "delta": { "omega_deg": [r,p,y], "t_m": [tx,ty,tz] },  // δ̂: rig pose correction
  "mode":         "whole_frame",
  "B":            128,                                   // sub-crops actually batched
  "cs":           256,
  "target_idx":   17,
  "pert_px_mean": 6.41,                                  // before correction (mean reproj px)
  "corr_px_mean": 0.45,                                  // after correction
  "took_s":       0.21,
  "overlay_url":  "/calibrate/result/overlay_....png"
}

Examples

curl — whole-frame on the default frame, perturb 0.3°/-0.2°/0.5° and 3/-2/4 cm:

curl -s -X POST http://172.16.200.185:8082/api/calibrate \
  -H "Content-Type: application/json" \
  -d '{"ypr":[0.3,-0.2,0.5],"t":[0.030,-0.020,0.040],
       "mode":"whole_frame","n_tiles":32,"cs":256,"target_idx":17}'

Python — pick a random fisheye frame from the catalog and calibrate:

import random, requests
BASE = "http://172.16.200.185:8082"
frames = requests.get(f"{BASE}/api/frames").json()["frames"]
target = random.choice(frames)["first_idx"]
r = requests.post(f"{BASE}/api/calibrate", json={
    "ypr": [0.3, -0.2, 0.5], "t": [0.030, -0.020, 0.040],
    "mode": "whole_frame", "n_tiles": 32, "cs": 256,
    "target_idx": target,
}).json()
print(f"δ̂ ω={r['delta']['omega_deg']} t={r['delta']['t_m']}")
print(f"reproj {r['pert_px_mean']:.2f}px → {r['corr_px_mean']:.2f}px in {r['took_s']}s")
print(f"overlay: {BASE}{r['overlay_url']}")

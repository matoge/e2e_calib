# torch 2.3.0a0 は numpy 1.x ABI でビルドされており、numpy 2.x を強制的に
# 入れると `UserWarning: _ARRAY_API not found` で torch.tensor/from_numpy 等が
# 半死する (2026-05-04 実証)。
# V3 cache (numpy 2.x pickled) の load は datasets/pandaset_full.py 側の
# pickle_shim (`numpy._core` → `numpy.core`) で吸収する。
# dataset 側で使っている: pandaset v3 (fsx cache) / waymo v3 cache は pt を直読。
# ただし V3 tile cache は JPEG bytes を .pt 内に保持しており、__getitem__ 側で
# PyTurboJPEG で decode する。base image には無いので明示的に入れる。
# NOTE: PyPI 名前衝突注意 — `turbojpeg` (Dobatymo/turbojpeg-python) は
# `TurboJPEG` class を持たず、pandaset_full.py の optional-import が silent
# fallback で PIL 経路に落ちる。必ず `PyTurboJPEG` (Lilohuang/PyTurboJPEG) を
# pin する。詳細は docs/sps_bottleneck_analysis.md §8.1。
